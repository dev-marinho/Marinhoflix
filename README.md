# Marinho — Portfólio de Videomaker

Portfólio em estilo de plataforma de streaming, feito em HTML, CSS e JavaScript puros (sem instalar nada).

## Como ver
Abra o `index.html` no navegador ou publique pelo **GitHub Pages**.

## Etapas
- [x] Abertura animada: **M → MARINHO** com som próprio (impacto + swoosh, livre de direitos)
- [x] Tela "Qual o seu negócio?" com 5 perfis
- [x] Página de cada perfil (destaque, Top 5, "Aprovado e publicado")
- [x] Menu superior e barra flutuante (Instagram, Orçamento, E-mail, perfis)
- [ ] Trocar vídeos de exemplo pelos vídeos reais
- [ ] Página "Conheça o meu trabalho"

## Onde editar
Todos os textos, contatos, perfis e vídeos ficam em **`js/data.js`**.
Os vídeos de exemplo estão em `assets/exemplos/` e podem ser apagados quando os reais entrarem.
